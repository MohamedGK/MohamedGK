### 🚀 Currently building — [Ariatoon](https://ariatoon.com)

A platform for **original Arabic manga, webtoons and novels**, on the web and on mobile.

- **Platform API** — Go service with PostgreSQL and Redis: authentication and sessions, content and chapters, a coins wallet with paid chapters, and payouts for creators.
- **Website & dashboards** — React Router (SSR) + TypeScript: the reading site, a creator studio and an admin dashboard, in Arabic (RTL) and multiple languages.
- **Mobile app** — Flutter app for Android and iOS on the same API.
- **Ariatoon Partners** — a separate ads program for creators: server-verified rewarded ads (AdMob, AppLovin, Unity LevelPlay), a double-entry earnings ledger, monthly payouts, and its own publisher and admin consoles.
- **Infrastructure** — Docker, Nginx and Cloudflare on Linux servers, with backups, monitoring and zero-downtime deploys.
